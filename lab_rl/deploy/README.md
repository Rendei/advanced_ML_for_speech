# Деплой на сервер (rendei-cool.ru)

Игровой сервер работает на CPU в **публичном режиме** (`--public`) с ограничениями (≤ 400 симуляций на ход, тело запроса ≤ 4 КБ,
≤ 4 одновременных расчётов бота, ≤ 120 запросов в минуту с адреса, таймаут чтения 10 с, заголовки безопасности).
Идеальный солвер («идеальный игрок» и вердикты) включён для **не более 3 одновременных запросов** (`--solver-slots 3` в
`docker-compose.prod.yml`; `0` выключает солвер совсем): это три процесса `c4solver` по ~115 МБ, запрос стоит единицы миллисекунд,
запрос дольше 30 с обрывается, четвёртый одновременный получает «занято, повторите». Книга солвера (32 МБ) скачивается при старте
контейнера в том `solver_cache`, туда же пишется кэш решённых позиций. Перед сервером стоит Caddy: он сам получает и продлевает
сертификат Let's Encrypt.

## Что нужно
* Сервер с Linux и доступом по SSH (root или пользователь с правом на Docker), 1–2 ГБ памяти, ~3 ГБ диска.
* DNS: A-записи `rendei-cool.ru` и `www.rendei-cool.ru` → IP сервера.
* Свободные порты 80 и 443 (старый сайт нужно остановить).

## Вариант 1: одной командой с вашего компьютера
```powershell
powershell -ExecutionPolicy Bypass -File lab_rl\deploy\deploy.ps1
```
Скрипт упаковывает проект, подключается к серверу **одним** SSH-соединением (пароль спросят один раз), распаковывает в `/opt/c4rl`
и запускает `deploy/remote.sh`. Два вопроса перед запуском: ставить ли Docker, если его нет, и останавливать ли то, что занимает порты 80/443.

## Вариант 2: вручную на сервере
```bash
# скопировать проект в /opt/c4rl (scp -r lab_rl root@IP:/opt/c4rl или git clone), затем:
cd /opt/c4rl
INSTALL_DOCKER=1 FREE_PORTS=1 sh deploy/remote.sh      # без флагов ничего не ставит и не останавливает
```
Сборка образа на сервере занимает несколько минут (компилируется солвер, ставится torch для CPU).

## Проверка и обслуживание
```bash
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f --tail 50 play caddy
curl -I https://rendei-cool.ru          # 200 и валидный сертификат
docker compose -f docker-compose.prod.yml up -d --build   # обновление после изменения кода
docker compose -f docker-compose.prod.yml down            # остановить
```

## Если сертификат не выдаётся
* DNS ещё не обновился: `nslookup rendei-cool.ru` должен показать IP сервера, подождите.
* Порты 80/443 закрыты межсетевым экраном хостера (нужны оба, плюс 443/udp для HTTP/3).
* Лимиты Let's Encrypt при многократных неудачных попытках — смотрите лог `caddy`.

## Безопасность
Сервис без авторизации: любой желающий может играть, но не может запустить ничего, кроме выбора колонки у бота. Пароль root,
который вы передавали открытым текстом, лучше сменить сразу после деплоя (`passwd`) и перейти на вход по ключу.
