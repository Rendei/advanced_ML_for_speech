# Лаба 1. Фузирование аудио и текста (IEMOCAP, cross-attention)

Реальные данные и готовые модели вместо синтетики. Показываем главное: **фузирование двух модальностей** (речь + транскрипт)
через **cross-attention** (Q = текстовые токены, K/V = аудио-кадры) и сравниваем его с моделями «до фузирования».

| Что | Чем |
|---|---|
| Данные | IEMOCAP (зеркало HF `Ar4ikov/iemocap_audio_text`, 10 039 реплик, 4 эмоции: neutral / happy(+excited) / sad / angry) |
| Аудио-энкодер | `microsoft/wavlm-base-plus`, заморожен |
| Текст-энкодер | `roberta-base`, заморожен |
| Обучается | маленькие головы (0.45–2.1 M параметров в зависимости от модели): энкодер-слой, cross-attention, классификатор |
| Протокол | leave-one-session-out (5 сессий, дикторы в тесте не встречаются в обучении), 3 seed'а |
| Гиперпараметры | по умолчанию — фиксированные; профиль `tuned`: случайный поиск (lr, d, dropout, weight decay, число cross-слоёв) отдельно для каждой модели и фолда, выбор **по валидационной сессии**, тест не используется |
| Метрики | UA (главная), WA, macro-F1; paired bootstrap 95 % CI для разницы моделей |

Сравниваются: только аудио, только текст (**до фузирования**), конкатенация (только как reference), **cross-attention
Q=текст K/V=аудио**, двунаправленный cross-attention (**после фузирования**).

## Запуск (Docker)

```bash
docker compose run --rm smoke     # 600 реплик, 2 фолда — проверка конвейера, несколько минут
docker compose run --rm lab       # полный эксперимент на GPU  -> outputs/report.html
docker compose run --rm lab-cpu   # то же на CPU (извлечение признаков ≈ час)
docker compose run --rm lab-tuned # + подбор гиперпараметров (8 конфигураций на модель и фолд), ≈ 1–1.5 ч на GPU -> outputs/tuned/report.html
docker compose run --rm test      # ruff + mypy --strict + pytest
```

Первый запуск скачивает датасет (~1.4 ГБ) и модели (~1 ГБ) в `./cache` (монтируется с хоста) и один раз извлекает признаки;
повторные запуски берут всё из кэша. Нужен доступ в интернет (Hugging Face). Для GPU нужен Docker Desktop с WSL2 и драйвер NVIDIA.

Результат: `outputs/report.html` (самодостаточный отчёт на русском: данные, схема, формы тензоров, таблицы, графики,
значимость, анализ), `outputs/figures/*.png`, `outputs/metrics.json`. **Отчёт формируется в рантайме** из чисел и графиков именно этого запуска.

## Структура

```
src/fusionlab/
  config.py      конфигурация и профили (smoke / standard / full)
  data.py        загрузка IEMOCAP, метаданные, потоковое декодирование аудио
  features.py    замороженные WavLM + RoBERTa -> последовательности признаков (кэш .npz)
  tensors.py     padded-батчи, leave-one-session-out
  models.py      унимодальные модели, конкатенация, cross-attention, bi-cross-attention
  train.py       обучение, предсказание, метрики, трассировка форм тензоров
  experiment.py  модели × сессии × seed'ы
  analysis.py    таблицы, bootstrap, комплементарность, примеры
  viz.py         графики
  report.py + report.html.j2   отчёт
tests/           быстрые тесты на случайных тензорах (без скачивания)
```

## Лицензии

IEMOCAP распространяется USC SAIL на условиях исследовательской лицензии; зеркало на HF используется только для учебной работы.
